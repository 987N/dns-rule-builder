# Scope of the manual-curated MIT license

The MIT license in `manual-curated-MIT.txt` applies only to the narrowly
authored domain facts in `config/curated/*.list` and their source-selection
metadata in `config/source-approvals.yaml`. It does not relicense the Builder,
other program source, generated upstream rule data, or third-party sources.

Each curated hostname is an exact match (`DOMAIN`) and is recorded with its
originating official service-network documentation in the source approval
profile. The files intentionally contain no copied third-party rule sets.
